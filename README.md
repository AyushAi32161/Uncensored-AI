# UAI Web Companion (unofficial)

A small Android WebView wrapper that opens https://uncensored.com/ai.
It is an unofficial companion and is not affiliated with or endorsed by Uncensored AI.

## Build
This project is configured to build a debug APK using the included GitHub Actions workflow.
Upload the project to a GitHub repository, then open Actions → Build Android APK → Run workflow.
Download `UAIWeb-debug-apk` from the completed workflow's Artifacts section.
Install the APK on your own Android phone. You may need to allow installation from the browser/file manager you use.

The website's own login, availability, terms, and features are controlled by the website. This app does not contain an AI model or bypass any website restrictions.
